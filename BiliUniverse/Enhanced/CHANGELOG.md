# v0.6.0

### 🆕 New Features
  * 新增 Biliverse 哔哩万象应用内设置面板入口，可直接在 BiliBili「我的」页面打开并修改 Enhanced 设置；关闭「我的」页面自定义功能时，该入口仍会保留。
  * 完善首页定制：支持配置首页顶栏左侧按钮、顶栏右侧按钮、标签栏右侧按钮、首页标签页、默认标签页和底部导航栏。
  * 重构分区页并接入 BiliBili 原生“自定义标签页”功能，提供按类别整理的近 60 个分区与服务选项，可在 App 内选择、排序或清空快捷访问。
  * 首页标签页与分区页快捷访问双向联动：在分区页保存的选项和顺序会同步用于首页标签栏，无需在模块参数中重复维护完整列表。
  * BoxJS 与应用内设置面板完整提供分区选择，以及手机版和 iPad 版「我的」页面的创作中心、推荐服务和更多服务选项；这些持久化设置不会加入 Surge 或 Loon 模块参数。
  * 为各受支持代理平台提供同版本的应用内设置页面、配置接口与静态配置产物，同时保留 BoxJS 常用选项配置。

### 🐛 Bug Fixes
  * 修复在分区页保存或清空快捷访问后，首页标签页未按 App 内保存结果生效的问题。
  * 修复首页标签页设置入口仍打开旧版分区页的问题。
  * 修复关闭「我的」页面自定义功能后 Biliverse 设置入口同时消失的问题。
  * 修复 Stash 无法加载分区列表处理脚本，导致原生分区与首页标签页联动失效的问题。
  * 更新已失效的自定义分区图标。

### ‼️ Breaking Changes
  * 模块、插件及静态配置产物前缀由 `BiliBili.Enhanced` 更名为 `Biliverse.Enhanced`；旧文件名不再发布，现有订阅需要改用新的文件名与下载地址。
  * 持久化设置与缓存空间由 `@BiliBili.Enhanced` 更名为 `@Biliverse.Enhanced`；旧空间中的设置与缓存不会迁移，升级后需要重新配置。

### 🔄 Other Changes
  * `[储存] 配置类型 (Storage)` 默认使用 `PersistentStore`；未显式设置时按 `database` → `$argument` → `PersistentStore` 合并。该选项只属于模块 argument，不会写入 BoxJS 或应用内设置的静态持久化配置。
